# CoSync
* built by [Heona L](http://github.com/heonaliu) and [Maya H](http://github.com/mayalh22)

## Live Link:
- http://startcosync.org

## Purpose:
- This was built to support young builders in collaboration of their projects and aspirations. Both Maya and I have experienced the feeling where we've wanted to build something yet didn't know where to look for others interested in collaborating on the same projects.
- We hope CoSync will connect builders across the world just as it has hackathons and project building has connected Maya and I

## Technical Stack:
- Built with Typescript, Tailwindcss, Nodejs, Cloudinary, Firestore (for backend), Google Maps API
- AI is used in execution of the app, but the ideation and process was thoroughly researched before deciding its implementation. It was guided with extremely specific specifications which took we took the time to account for user safety and privacy.

## Challenges Encountered:
- We had to find a place that'd allow the uploading of images and connect it with our app. So we resorted to Cloudinary.
- We also had to consider privacy and how much we wanted users to input their personal information. This led to careful consideratoins on not adding chats.

## Future Improvements
- If we were to improve this project for the future, we'd have approved educators and a markdown style journal entries!
